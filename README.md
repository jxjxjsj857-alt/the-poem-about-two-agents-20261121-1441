A short poem about agency — the power to choose and to act — told as two
agents who disagree, listen, and agree: two minds, two maps, one road, and a
third way found together. `main.py` writes the poem to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only, no network) writes the poem —
267 Unicode code points, inside the 1–280 limit — to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` overrides the output directory for local runs). Every
run writes the same text.

## The poem

> Two minds, two maps, one road between them.
> I said go left. You said go right.
> We stopped, and listened to the quiet between us —
> and there it was: a third way, lit by both our lights.
> No voice won. No voice was lost.
> Two wills, one yes — we chose, and moved as one.
